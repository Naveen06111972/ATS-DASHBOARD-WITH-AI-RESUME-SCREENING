# ATS-DASHBOARD-WITH-AI-RESUME-SCREENING
A CLEAN DASHBOARD COMPONENT FOR AN ATS THAT LISTS JOB APPLICANTS WITH THEIR NAME ,STATUS AND AI SCORE.FOR THE AI LAYER WRITE A NODE.JS BACKEND FUNCTION THAT TAKES A CANDIDATES'S RESUME STRING SENDS THEM TO THE CLAUDE API AND RETURN A JSON OBJECT CONTAINING KEY SKILLS,MISSING AN OVERALL FIT RATING OUT.FOR AI LAYER WRITE A BACKEND FUNCTION THAT TAKES A CANDIDATE'S RESUME STRING AND A JOB DESCRIPTION STRING ,SENDS THEM TO THE CLAUDE API AND ETURNS A JSON OBJECT CONTAINING SKILLS MISSING AN OVERALL FIT RATING OUT OF 100
